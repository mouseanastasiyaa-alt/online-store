# Online Store 

Учебный проект интернет-магазина на Django, разрабатываемый в рамках курса.

## Описание

Проект представляет собой интернет-магазин плагинов и примеров кода (Skystore) с блогом.
Реализованы:
- каталог товаров с пагинацией,
- страница товара,
- CRUD для товаров через веб-интерфейс,
- форма обратной связи,
- блог с полным CRUD, счётчиком просмотров и фильтрацией публикаций,
- валидация форм (запрещённые слова, отрицательная цена, формат и размер изображения).

## Стек

- Python 3.14
- Django 6.1.1
- PostgreSQL 18
- Bootstrap 5 (CDN)
- Pillow (изображения)
- python-dotenv (переменные окружения)
- ipython (интерактивная консоль)

## Установка и запуск

1. Клонировать репозиторий:

   git clone https://github.com/mouseanastasiyaa-alt/online-store.git
   cd online-store

2. Создать и активировать виртуальное окружение:

   python -m venv .venv
   .venv\Scripts\activate    # Windows

3. Установить зависимости: 
   
   pip install -r requirements.txt

4. Создать .env на основе .env.sample и подставить свои значения:

   copy .env.sample .env

5. Применить миграции:

   python manage.py migrate

6. Загрузить тестовые данные (опционально):

   python manage.py load_test_data

7. Запустить сервер:

   python manage.py runserver

8. Открыть в браузере:

   http://127.0.0.1:8000/

# Функционал

## Каталог

1. писок товаров с пагинацией (3 на страницу).

2. Страница товара с полной информацией.

3. Создание, редактирование, удаление товара через веб-интерфейс.

### Валидация формы:

   1. запрещённые слова в названии и описании (регистронезависимо),

   2. цена не может быть отрицательной,

   3. изображение только JPEG/PNG, до 5 МБ.

## Блог  

1. Список опубликованных статей.

2. Просмотр статьи со счётчиком просмотров.

3. Создание, редактирование, удаление статьи.

4. При достижении 100 просмотров статьи — письмо на почту (console backend в разработке).

## Контакты

1. Страница с контактной информацией.

2. Форма обратной связи с сохранением в БД.

## Ветки

main — стабильная версия (релизы)

develop — ветка разработки

feature/* — ветки под отдельные задачи
